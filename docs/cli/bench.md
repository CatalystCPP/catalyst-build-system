# catalyst bench

```
Execute all benchmarks of a local package. 


catalyst bench [OPTIONS]


OPTIONS:
  -h,     --help              Print this help message and exit 
  -P,     --params TEXT ...   Params to pass to the bench executable. 
```

## Usage
`catalyst bench [OPTIONS]`

## Options
- `-P, --params TEXT ...`: Params to pass to the bench executable.
- `-h, --help`: Print help message.
